# Sistema de Consulta Mecânica

Projeto desenvolvido durante as aulas de Java no SENAI para praticar Programação Orientada a Objetos.

O sistema representa uma oficina mecânica, permitindo cadastrar veículos e consultar os veículos registrados e seus status.

## Funcionalidades

- Cadastro de veículos
- Consulta dos veículos cadastrados
- Consulta do status
- Diferentes tipos de veículos: carro, moto e mobilete
- Validação de alguns dados

## Conceitos utilizados

O projeto utiliza alguns dos principais conceitos que estou estudando em Java:

- Classes e objetos
- Herança
- Encapsulamento
- Construtores
- `ArrayList`
- `Scanner`
- Estruturas condicionais e de repetição
- Tratamento de exceções

## Estrutura

A classe `Veiculo` serve como base para os diferentes tipos de veículos:

```text
Veiculo
├── Carro
├── Moto
└── Mobilete
```

O programa é executado pela classe `Main`, onde é possível acessar as opções pelo terminal.

## Tecnologias

## Como executar

Clone o repositório:

```bash
git clone https://github.com/ArturTeschdosSantos/Atividade-aula-java.git
```
